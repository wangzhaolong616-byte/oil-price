4GitHub 是什么（大白话版）

你可能会觉得 GitHub 是程序员才用的东西，其实对你来说，它在这里扮演的角色就两个：一个网盘 + 一个自动机器人。

角色一：网盘（存代码和网页）

你的网页文件、数据文件都存放在 GitHub 的仓库里。免费、无限期、不会因为你关机就消失。

角色二：自动机器人（定时干活）

GitHub 有个叫 Actions 的功能，可以设定"每天几点做什么"。你的项目就是靠它每天自动抓油价、更新网页。

四个关键词，一次搞懂

词大白话解释在你的项目里具体指什么
仓库
Repository		 就是一个文件夹，存在 GitHub 的服务器上 你有一个仓库叫 oil-price，里面装着全部 19 个文件
Actions 自动机器人。你告诉它"每天几点干什么"，它就照做 每天跑 3 次的 update-oil-price 任务
Pages 免费网页托管。把仓库里的文件变成一个真正的网址 把 docs 文件夹变成你手机能打开的网址
Secrets 加密保险箱。存密码用的，存进去连自己也看不到 存你的邮箱授权码（如果配了邮件提醒的话）

公开会不会泄露隐私？ 仓库里只有代码和公开的油价数据，没有任何你的个人信息。你的邮箱授权码存在加密的 Secrets 里，公开仓库也看不到。

9出问题了怎么办（FAQ）

Q1：网页打不开怎么办？

国内访问 github.io 大部分时候是通的（我实测直连 1.1 秒），但偶尔会抽风。按顺序试：

  1. 刷新几次，或者换个网络（切 4G / 换 WiFi）
  2. 等一下再试——通常是临时的网络抖动
  3. 用离线版：如果你之前存过 oil-price-offline.html，那个永远能打开
  4. 告诉我，我可以给项目加一个备用访问通道（比如 Cloudflare 镜像）

Q2：数据好像没更新？

先确认三件事：

  1. 看网页标题下面的「数据更新」时间，是不是今天
  2. 去 Actions 页面看有没有绿色勾
  3. 确认今天是不是调价日——国内油价不是每天变的，每 10 个工作日才调一次。非调价日价格本来就不变，只是国际原油曲线在动

Q3：预测准不准？

请把预测当成"参考"而不是"结论" 它的算法是：用最近 8 次调价的间隔天数中位数，推算下次窗口日期；再用最近 140 次历史调价数据，拟合出"国际原油变化 1% 对应国内调多少元"的系数，据此估算幅度。

几个已知的偏差来源：
· 节假日：遇到春节等长假会顺延，可能差 1~2 天
· 搁浅机制：调价金额不足 50 元/吨时国家不调，这时候预测会说"可能搁浅"
· 窗口刚开始时：如果昨天刚调过价，本轮窗口才走 1 天，数据不够，预测会标注"参考值会随交易日累积修正"

最终一定以国家发改委的公告为准。

为什么搞这么多个源？ 部署时实测发现：FRED 和国内源在历史上高度吻合（偏差 0.3%~1.5%），但 FRED 最近几天偶尔会出异常数据——2026 年 9 月实测布伦特差了 20 美元。我用腾讯做第三方交叉验证，确认是国内源对的。

所以脚本里做了一套多源对账：国内源为主，FRED 只用来补 2016 年前的历史（补之前还会自动做量级校准），实时报价两个通道互为备份。任何一个源挂了，都不会影响你看到的曲线。
